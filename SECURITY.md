# Security policy

## Reporting a vulnerability

Please report vulnerabilities **privately**, not in public issues: use GitHub's
**Security › Report a vulnerability** on this repository (private vulnerability reporting).

Include the Fudo version, the steps to reproduce and the impact you see. You will get an answer
as soon as possible; please give a reasonable time to fix the problem before disclosing it.

## Supported versions

Security fixes go into the latest release. Upgrading is described in
[docs/admin/upgrading-and-backup.md](docs/admin/upgrading-and-backup.md).

How Fudo protects accounts and data: [docs/admin/security.md](docs/admin/security.md).
