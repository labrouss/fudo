# Έννοιες

## Πεδία: μισθωτές και καθολική υποδομή

| Πεδίο | Περιέχει | Τη διαχειρίζονται |
|---|---|---|
| **Μισθωτής** (ένας ανά επιχειρησιακή μονάδα) | τις εφαρμογές, τις παρακολουθήσεις, τους πόρους, τα κανάλια και τις αναφορές του | διαχειριστές μισθωτή |
| **Καθολική υποδομή** | κοινούς πόρους (μεταγωγείς, αποθηκευτικά συστήματα, δίκτυα FC, συστοιχίες) και τις παρακολουθήσεις τους | διαχειριστές υποδομής και superadmin |

Επιλέξτε το πεδίο από τον επιλογέα στο πάνω μέρος της πλαϊνής μπάρας. Οι μισθωτές βλέπουν την
κοινή υποδομή μόνο για ανάγνωση και συνδέουν σε αυτήν τις δικές τους παρακολουθήσεις και
εφαρμογές, έτσι μια βλάβη στο αποθηκευτικό σύστημα εμφανίζεται ως αιτία σε κάθε εφαρμογή που
το χρειάζεται.

## Δομικά στοιχεία

| Στοιχείο | Τι είναι | Παράδειγμα |
|---|---|---|
| **Παρακολούθηση** | ένας έλεγχος που εκτελείται σε τακτά διαστήματα | HTTPS στο `erp.corp.local/health` |
| **Πόρος** | ένα κομμάτι υποδομής, που ελέγχεται από τις παρακολουθήσεις του | `Core-SW-01`, `SAN-A` |
| **Εφαρμογή** | μια επιχειρησιακή υπηρεσία: παρακολουθήσεις (μέλη) και η υποδομή που χρειάζεται | *ERP Production* |
| **Εξάρτηση** | «αυτό χρειάζεται εκείνο»: πόρος → πόρος, εφαρμογή → πόρος | συστοιχία ESXi → SAN-A |

```
application ──members──▶ monitors ──check──▶ asset ──depends on──▶ asset …
     └──────────────────depends on──────────────────▶ asset
```

Σε έναν πόρο, η **Προσθήκη υπαρχουσών** τοποθετεί σε αυτόν παρακολουθήσεις που ήδη έχετε (όποια βρίσκεται σε άλλον πόρο μεταφέρεται) και η **Νέα παρακολούθηση** ανοίγει τη φόρμα παρακολούθησης γι' αυτόν. Ένας μισθωτής μπορεί επίσης να τοποθετήσει τις δικές του παρακολουθήσεις σε κοινό καθολικό πόρο· η **Αφαίρεση** βγάζει μια παρακολούθηση από τον πόρο και τη διατηρεί.

## Καταστάσεις

| Κατάσταση | Σημασία |
|---|---|
| **Σε λειτουργία** | λειτουργεί |
| **Υποβαθμισμένο** | λειτουργεί, αλλά αργά ή μερικώς (π.χ. ένα προαιρετικό μέλος είναι εκτός λειτουργίας) |
| **Εκτός λειτουργίας** | αποτυγχάνει, και τίποτα από όσα εξαρτάται δεν το εξηγεί: είναι **βασική αιτία** |
| **Επηρεασμένο** | αποτυγχάνει **επειδή** κάτι από το οποίο εξαρτάται είναι εκτός λειτουργίας· οι ειδοποιήσεις δείχνουν τη βασική αιτία |
| **Σε κίνδυνο** | λειτουργεί, αλλά κάτι από το οποίο εξαρτάται έχει πρόβλημα |
| **Συντήρηση** | σε προγραμματισμένο παράθυρο συντήρησης: δεν μετρά στη διαθεσιμότητα |
| **Σε αναμονή** | δεν υπάρχει ακόμη αποτέλεσμα |

## Πώς το Fudo βρίσκει τη βασική αιτία

| Κατάσταση | Αποτέλεσμα |
|---|---|
| Οι έλεγχοι ενός πόρου αποτυγχάνουν και τίποτα από όσα εξαρτάται δεν είναι εκτός λειτουργίας | **Εκτός λειτουργίας**: βασική αιτία, με δικό του συμβάν |
| Οι έλεγχοί του αποτυγχάνουν **και** κάτι από όσα εξαρτάται είναι εκτός λειτουργίας | **Επηρεασμένο από** αυτή τη βασική αιτία: χωρίς καταιγισμό ειδοποιήσεων |
| Οι έλεγχοί του περνούν αλλά κάτι από όσα εξαρτάται είναι εκτός λειτουργίας | κρατά την κατάστασή του, με την ένδειξη **Σε κίνδυνο** |
| Κάτι από όσα εξαρτάται είναι σε προγραμματισμένη συντήρηση | **Επηρεασμένο από συντήρηση** (προγραμματισμένο, εκτός διαθεσιμότητας) |

Μια εφαρμογή είναι υγιής όταν τα μέλη της είναι, σύμφωνα με τον κανόνα της: **όλα τα
υποχρεωτικά μέλη σε λειτουργία**, **τουλάχιστον ένα**, ή **τουλάχιστον N από M** (για
πλεονάζουσες υπηρεσίες). Τα υποχρεωτικά μέλη καθορίζουν την κατάσταση· τα προαιρετικά μπορούν
μόνο να την κάνουν *Υποβαθμισμένη*.

Το **Τι γίνεται αν αυτό αποτύχει;** σε έναν πόρο προβλέπει ποιες εφαρμογές θα σταματούσαν, και
ποιες θα άντεχαν χάρη στον πλεονασμό, πριν τον βγάλετε εκτός για εργασίες.

Η σελίδα **Τοπολογία** σχεδιάζει όλη την εικόνα με ζωντανή κατάσταση: περάστε τον δείκτη πάνω
από ένα στοιχείο για να δείτε τις εξαρτήσεις του· το *Μόνο προβλήματα* δείχνει τι αποτυγχάνει
και τι εξαρτάται από αυτό.
