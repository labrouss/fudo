# Παράθυρα συντήρησης

Προγραμματίστε εργασίες ώστε να μην ειδοποιείται κανείς και να μη μετρούν στη διαθεσιμότητα.

**Συντήρηση › Προγραμματισμός συντήρησης**: δώστε τίτλο, έναρξη και λήξη, σημειώσεις (αίτημα
αλλαγής, υπεύθυνος επικοινωνίας, σχέδιο επαναφοράς) και τι **καλύπτει**: πόρους (με τους
ελέγχους τους) και παρακολουθήσεις.

Κατά τη διάρκεια του παραθύρου:

- οι έλεγχοι συνεχίζουν να εκτελούνται, ώστε να βλέπετε τι συμβαίνει,
- τα αποτελέσματά τους **εξαιρούνται από τη διαθεσιμότητα** και το SLA,
- οι **ειδοποιήσεις σιωπούν**,
- όσα εξαρτώνται από κάτι σε συντήρηση το δείχνουν ως αιτία (*Επηρεασμένο από συντήρηση*), ώστε
  κανείς να μην κυνηγά μια προγραμματισμένη διακοπή.

Η **Λήξη τώρα** τερματίζει ένα παράθυρο νωρίτερα. Τα παράθυρα εμφανίζονται ως
*Προγραμματισμένο*, *Σε εξέλιξη* ή *Ολοκληρώθηκε*.

Συμβουλή: χρησιμοποιήστε πρώτα το **Τι γίνεται αν αυτό αποτύχει;** στον πόρο, για να δείτε
ποιες εφαρμογές θα επηρεάσει η εργασία.

## Επαναλαμβανόμενη συντήρηση

Επιλέξτε **Επανάληψη** κατά τον προγραμματισμό: κάθε μέρα, κάθε εβδομάδα σε επιλεγμένες ημέρες, ή
κάθε μήνα, σε μια ημέρα του μήνα (η 31η πέφτει στην τελευταία ημέρα των μικρότερων μηνών) ή σε μια
ημέρα μιας εβδομάδας (η *Τρίτη της δεύτερης εβδομάδας* είναι το Patch Tuesday της Microsoft). Οι ώρες
είναι στη ζώνη ώρας που επιλέγετε, οπότε οι 02:00 μένουν 02:00 και μετά την αλλαγή ώρας· ώρα λήξης
πριν από την έναρξη σημαίνει την επόμενη μέρα.

Το Fudo δημιουργεί τα παράθυρα των επόμενων 60 ημερών, με την ένδειξη **Επαναλαμβάνεται**. Η
**Παράλειψη** αφαιρεί μία εμφάνιση, και η επεξεργασία ενός παραθύρου αλλάζει μόνο αυτήν. Η
επεξεργασία της σειράς αλλάζει τα μελλοντικά της παράθυρα· η διαγραφή της τα αφαιρεί, ενώ τα
προηγούμενα και όσα εκτελούνται παραμένουν.
